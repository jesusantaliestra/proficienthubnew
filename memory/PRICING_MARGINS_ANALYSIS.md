## 8. PRICING FORMULAS

### License Price Calculation
```
License_Price = (Base_Cost × Volume_Multiplier) + AI_Tutor_Price

Example: 20 exams + Standard AI + 500 licenses
= ($18.80 × 1.85) + $9.00
= $34.78 + $9.00
= $43.78 per license
```

### Package ROI Calculation
```
ROI% = ((Revenue - Cost) / Cost) × 100

Example: 1000 Writing Tests @ $5 sell price
Cost = $50 (1000 × $0.05)
Revenue = $5,000 (1000 × $5)
Profit = $4,950
ROI = 9,900%
```

## 10. RECOMMENDED PRICING STRATEGY

### For Institutions Reselling to Students:

1. **Writing Tests**: Recommend 3-5x markup ($3-5 per test) for 85-95% margin
2. **Speaking Tests**: Recommend 2-3x markup ($5-8 per test) for 50-70% margin  
3. **Mock Exams**: Recommend 2-4x markup ($5-10 per exam) for 50-75% margin
4. **AI Tutor**: Already priced for end-consumer, include in license or add $2-5/student

### Volume Incentives:
- Push customers to 501+ license tier for better conversion (14% discount)
- Enterprise deals (2001+) require custom negotiation
